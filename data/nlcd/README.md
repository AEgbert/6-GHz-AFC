# Modified National Land Cover Database (NLCD) Repository
## Related Standard
This repository contains a modified version of the National Land Cover Database (NLCD) for determining clutter loss during 6 GHz AFC operation as defined in [WINNF-6GHz-0006](https://winnforum.org/cmte-policies/). This data has been modified according to the process specified in [WINNF-TS-1014](https://winnforum.org/specifications/#6-ghz-specifications) Annex F.

## Notifications
To receive notifications of when this data repository is updated, consider using a [file watcher service](https://app.github-file-watcher.com/) to monitor [this GitHub repository](https://github.com/Wireless-Innovation-Forum/6-GHz-AFC) and the `data/nlcd/*` subdirectory. Additionally, modifications to this data repository will be made via pull requests submitted to this GitHub repository.
