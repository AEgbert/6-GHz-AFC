# 6 GHz AFC Data Repositories

This directory contains data repositories related to the operation and testing of 6 GHz Automated Frequency Coordination (AFC) systems.

## Notifications
To receive notifications of when a data repository in this directory is updated, consider using a [file watcher service](https://app.github-file-watcher.com/) to monitor [this GitHub repository](https://github.com/Wireless-Innovation-Forum/6-GHz-AFC) and the `data/*` subdirectory. Additionally, modifications to these data repositories will be made via pull requests submitted to this GitHub repository.

## Published Data Repositories
Published data repositories are listed below. For specific information or version history regarding a specific dataset, see the `README.md` file included in each directory.
  * Supplementary Data Repository (`./common_data`)
	  * Managed according to [WINNF-TS-5008](https://6ghz.wirelessinnovation.org/baseline-standards). Contains multiple repositories for AFC System operation.
  * FCC Universal Licensing System Snapshot Repository (`./uls_snapshot`)
	  * Managed by Wi-Fi Alliance. Snapshot used for AFC System lab testing.
  * National Land Cover Database (NLCD) Repository (`./nlcd`)
	  * Managed according to [WINNF-6GHz-0006] (https://winnforum.org/cmte-policies/) Annex A. Provides NLCD information modified to provide a more accurate estimate of the clutter environment (e.g., remove urban classification from roads in rural areas).
  * Site-Specific DSM/DEM Repository (`./dsm_dem`)
	  * Managed according to [WINNF-6GHz-0006](https://winnforum.org/cmte-policies/) Annex B. Provides site-specific high-resolution surface (DSM) and bare-earth (DEM) heights around individual incumbent Fixed Service receivers.
